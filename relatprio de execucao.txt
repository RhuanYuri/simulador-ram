1. INTRODUÇÃO
A memória RAM é um dos principais componentes da arquitetura de computadores, sendo responsável pelo armazenamento temporário de dados e informações utilizadas durante a execução de programas. O acesso à memória é realizado por meio de endereços, permitindo que o processador identifique a posição na qual determinado dado está armazenado.
Com o objetivo de facilitar a compreensão desses conceitos, este projeto propõe o desenvolvimento de um simulador de memória RAM em linguagem C, capaz de representar, de maneira simplificada, operações fundamentais de uma memória, como escrita, leitura, sobrescrita e consulta dos dados armazenados.
O simulador será executado por meio de uma interface interativa no terminal, permitindo ao usuário informar um endereço de memória e um dado a ser armazenado, consultar valores previamente registrados e visualizar o estado da memória. Dessa forma, o projeto busca relacionar os conceitos teóricos estudados na disciplina de arquitetura de computadores com uma implementação prática desenvolvida em linguagem C.

2. JUSTIFICATIVA
A memória RAM exerce papel fundamental no funcionamento de um computador, pois possibilita o armazenamento temporário de informações necessárias para a execução dos programas. A compreensão de conceitos como endereçamento, leitura, escrita e armazenamento de dados é importante para o estudo da organização e arquitetura de computadores.
A implementação de um simulador em linguagem C permite representar esses conceitos de forma prática, proporcionando uma visão simplificada do funcionamento de uma memória. O uso da linguagem C também contribui para a compreensão de estruturas de dados, vetores, funções, ponteiros e gerenciamento de informações em baixo nível, conceitos diretamente relacionados à área de arquitetura de computadores.

4. IMPLEMENTAÇÃO
O código implementa um simulador em C que modela o comportamento básico de uma memória RAM de 256 posições. A estrutura central do programa é definida pela struct MemoriaRAM, que abstrai o espaço de endereçamento utilizando vetores para armazenar os dados em bytes (uint8_t), controlar a ocupação das posições e contabilizar as operações realizadas. Através de rotinas dedicadas de validação e gerenciamento, o sistema garante que apenas endereços válidos (de 0 a 255) e valores no limite de 8 bits (de 0 a 255) sejam processados. A seguir as pode-se visualizar as funcionalidades do programa:

A dinâmica de funcionamento simula as operações fundamentais de barramento e armazenamento de uma memória real. Na rotina de escrita, o programa verifica se o endereço já possui dados, sobrescreve o valor se necessário e marca a posição como ocupada. Na operação de leitura, ele consulta o estado da célula antes de retornar o dado contido nela. Além disso, a aplicação mantém estatísticas de acesso e oferece funções para exibir o mapa de memória, listando apenas os endereços efetivamente utilizados, e para restaurar todo o espaço ao estado inicial zerado.

A interação com o usuário é gerida por um menu em laço de repetição (do-while) operado via comandos de terminal. A implementação conta com tratamento de erros de entrada de dados, utilizando validações no retorno da função scanf e a rotina limpar_buffer para evitar travamentos decorrentes de resíduos no buffer do teclado.
